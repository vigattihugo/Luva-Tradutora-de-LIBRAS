# Luva-Tradutora-de-LIBRAS

# O que é
Protótipo assistivo que interpreta gestos da Língua Brasileira de Sinais (LIBRAS) via sensores flexíveis em uma luva, convertendo movimentos em texto exibido em tempo real no computador.

# Problema resolvido
Barreira de comunicação entre pessoas surdas e ouvintes que não dominam LIBRAS, propondo uma alternativa de baixo custo frente às tecnologias assistivas tradicionais.

# Especificações técnicas
- Arduino Uno Nano com 4 sensores flex para leitura da curvatura dos dedos
- Sistema de calibração para mapear posição neutra e reduzir ruídos
- Lógica de reconhecimento de padrões gestuais; saída via comunicação serial USB
- Linguagem C/C++ (nível acadêmico)

# Resultados
- Reconhecimento bem-sucedido dos primeiros gestos programados (Oi, Tudo bem?, Quero beber água) em tempo real
- Validação do conceito como solução assistiva viável, com base para evoluções futuras
